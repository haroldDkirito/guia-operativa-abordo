# Guía Operativa Digital ABORDO — Web v10

Evolución del prototipo `Guia_Rapida_ABORDO_Prototipo_v5.html` para uso móvil/escritorio y despliegue directo en GitHub Pages.

## Principales mejoras

- Interfaz moderna con identidad ABORDO (`#071d4f` y `#09a6b4`).
- Modo claro/oscuro persistente.
- Búsqueda en vivo y resaltado de coincidencias.
- Filtros por categoría.
- Pestañas principales.
- Checklist interactivo con progreso y `localStorage`.
- Galería dinámica de infografías.
- Videos reales de capacitación.
- Modales accesibles con animación, Escape y clic fuera.
- Botón “volver arriba”.
- Acceso directo a Mesa de Control por WhatsApp.
- `loading="lazy"` en imágenes.
- Metadatos SEO/Open Graph.
- CSS y JavaScript separados para facilitar mantenimiento.

## Publicar en GitHub Pages

1. Verifica que `index.html` esté en la raíz.
2. En GitHub: **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige `main` y `/ (root)`.
5. Guarda y espera a que GitHub publique la URL.

## Actualizar contenido

### Accesos rápidos
Edita `quickCards` en `assets/js/app.js`.

### Procedimientos
Edita `topics`.

### Infografías
Copia nuevas imágenes a `assets/img/` y actualiza `infographics`.

### Videos
Actualiza `videos` y coloca los MP4 en `assets/video/`.
